# Objetivos del proyecto

## Objetivo general
Desarrollar un prototipo funcional basado en Arduino capaz de gestionar el envío de una señal de aviso o emergencia.

## Objetivos específicos
- Definir la estructura hardware del dispositivo.
- Programar la lógica principal de funcionamiento.
- Gestionar la lectura del botón de activación.
- Monitorizar el estado de la batería.
- Implementar la comunicación entre módulos.
- Realizar pruebas funcionales e integración.
