# ARGUSLINK

Proyecto de desarrollo de un prototipo basado en Arduino dentro del macroproyecto ARGUSLINK.

## Estructura del repositorio

- docs: documentación técnica y funcional
- hardware: componentes, esquemas y montaje
- firmware: código fuente del dispositivo

## Flujo de trabajo

- main: versión estable
- dev / ramas personales: desarrollo y pruebas
- feature/*: tareas concretas del equipo

## Objetivo inicial

Desarrollar un dispositivo capaz de gestionar una señal de aviso/SOS, integrando hardware, comunicaciones y lógica de control.
